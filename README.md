# HackTeam Portal - Hackathon Team Formation Portal
Node.js + Express + MongoDB (Mongoose) + Bootstrap 5.

## Features
1. Team Balance Score (role diversity + experience mix + skill breadth) with animated ring
2. Smart Match: ranks open teams for a participant with match % and reasons
3. Auto Team Builder: preview and save role-balanced teams from unassigned participants
4. Live dashboard: animated stats and talent-pool-by-role chart
5. "Looking for" roles + balance tips, join/leave teams (leadership transfer), sort and search
6. Avatars, dark mode, confetti, animations; client + server validation

## Run
npm install, add MONGODB_URI to .env, npm start -> http://localhost:3000
## Deploy: push to GitHub, import in Vercel, add MONGODB_URI env var, deploy.
